# PostgreSQL indexes
Inspect pg_indexes, pg_index, pg_constraint and pg_stat_user_indexes; statistics are cumulative and may reset. B-tree covers common equality/range/order; GIN for supported membership/text operators, GiST/SP-GiST for suitable operator classes, BRIN for correlated large tables. Evaluate partial indexes, INCLUDE and expression indexes. Foreign keys do not automatically create child-side indexes. Check index-only heap fetches, invalid indexes, predicate implication and actual buffers. CREATE INDEX CONCURRENTLY has restrictions, extra work and cannot run in a transaction block; failed builds may leave invalid indexes. Confirm version and migration tooling.
