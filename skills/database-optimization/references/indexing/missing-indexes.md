# Missing indexes
Collect expensive query fingerprints and map WHERE, JOIN, ORDER BY and GROUP BY to existing indexes. Inspect actual vs estimated cardinality, loops, rows filtered, IO and sorts. Check child-side foreign key lookup patterns (automatic indexing varies by engine). Evaluate selectivity, existing prefix coverage and whether rewriting predicates is preferable. Propose candidate DDL with target query, expected access path, size/write costs and rollout plan. Test on representative data. Missing-index suggestions from engines are heuristics, not instructions to create every proposed index.
