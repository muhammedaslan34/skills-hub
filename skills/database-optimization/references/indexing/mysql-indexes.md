# MySQL indexes
Inspect SHOW INDEX or information_schema.statistics and Performance Schema if enabled. InnoDB primary key is clustered; secondary indexes carry primary key values, so wide PKs increase storage. Foreign key supporting indexes may be created automatically; verify definitions. Evaluate leftmost prefixes, covering access, functional indexes (version-dependent) and optimizer behavior. Invisible indexes can help controlled removal testing on supported versions but still have maintenance costs and constraints. Verify online DDL algorithm/lock support, metadata locks and replica impact before applying changes.
