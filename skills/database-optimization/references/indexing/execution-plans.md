# Execution plans
Use estimated EXPLAIN first. Actual-plan commands execute statements; run only approved representative read queries with resource limits. Compare estimated/actual rows, loops, scan and join methods, filters, sort/spill, IO/buffers and elapsed time. Multiply per-loop work where applicable; do not compare cost units across engines. Investigate stale statistics, parameter skew, non-sargable predicates and fan-out before creating indexes. PostgreSQL: EXPLAIN (ANALYZE, BUFFERS); MySQL 8.0.18+: EXPLAIN ANALYZE; SQLite: EXPLAIN QUERY PLAN; SQL Server: estimated plan or authorized actual plan and STATISTICS IO/TIME. Test equivalent workload before/after.
