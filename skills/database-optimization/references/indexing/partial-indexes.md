# Partial and expression indexes
PostgreSQL and SQLite support partial indexes; SQL Server supports filtered indexes with restrictions. MySQL has no general partial index predicate; generated columns or functional indexes may help specific cases, with different semantics. Example PostgreSQL: CREATE INDEX ... ON reservations(property_id, check_in_date) WHERE status = 'confirmed'. Ensure query predicates imply the index predicate; parameterized/generic plans can affect eligibility. Expression indexes require matching expressions, types and engine-specific determinism rules. Verify soft-delete and uniqueness semantics and avoid indexing moving time windows with nonimmutable predicates.
