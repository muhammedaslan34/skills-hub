# Index audit fundamentals
Start with observed workload, schema, existing definitions, constraints, statistics and table sizes. Rank query fingerprints by total cost, latency and business importance. Evaluate B-tree for equality/range/order; specialized types depend on engine and operators. Indexes trade faster reads for storage, writes and maintenance. A sequential scan can be correct for small tables or broad predicates. Review missing, composite, covering, partial, expression and redundant indexes; consider foreign key joins and parent deletes. Verify with plans and comparable measurements. Consult engine guides before DDL. Never infer a missing index from a column name alone.
