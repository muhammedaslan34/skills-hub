# MySQL
Identify version and storage engine. Use EXPLAIN or supported EXPLAIN ANALYZE on approved representative SELECTs (ANALYZE executes the query). Review access type, estimated/actual rows, chosen keys, loops, temporary tables and filesort in context. Use Performance Schema, sys schema or slow query logs when authorized; avoid logging secrets. Inspect composite index leftmost prefixes, covering indexes and actual selectivity. Check InnoDB locking, isolation and transaction duration. Evaluate online DDL support and deployment impact for the specific version; do not assume schema changes are lock-free. Avoid redundant indexes and deep OFFSET where keyset pagination fits.
