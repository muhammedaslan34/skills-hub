# Skills Hub

A collection of reusable AI coding agent skills for Codex, Claude Code and other compatible agents.

## Available skills

- [Database Optimization](skills/database-optimization/SKILL.md): Prevent and audit N+1 queries, inefficient SQL, indexing, pagination and database performance regressions across ORMs.

## Installation

Clone this repository and copy the desired skill directory into your agent's skills directory (for example, `~/.agents/skills/` or `~/.claude/skills/`).

Each skill contains its own instructions and supporting references.
